Built a full-stack AI-powered Expense Tracker using Spring Boot, React, and MySQL for efficient personal finance management.
Implemented AI-based financial insights using Spring AI and Ollama to analyze expenses, detect overspending, and provide smart saving recommendations.
Developed monthly and overall expense analytics with category-wise spending summaries, budget tracking, and personalized AI-generated financial suggestions.
Designed a responsive and modern dashboard UI with React, including budget management, expense tracking, AI insights pages, loading animations, and toast notifications.
Added secure session-based authentication, CRUD operations for expenses and budgets, and intelligent financial reporting for improved budgeting and expense monitoring.
